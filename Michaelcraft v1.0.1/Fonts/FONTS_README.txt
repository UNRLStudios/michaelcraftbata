MICHAELCRAFT FONTS (Beta 1.3.2)
===============================

The game's writing is in MINECRAFTIA (by Andrew Tyler, 2014).
    License: Creative Commons Attribution Share Alike (CC BY-SA)
It is BUILT INTO index.html, so it works everywhere: opened from a folder, on phones,
and on computers that don't have the font installed. Nothing to do.

Minecraftia draws its letters well above their baseline, so out of the box text sits
too high in every button and box. The copy in the game is FIXED: every letter moved
down onto the baseline (and sensible line heights). Minecraftia-MichaelCraft.ttf in
this folder is that fixed copy (shared under the same CC BY-SA license).

Backup pixel font (only used if something goes wrong): MinecraftFallback.ttf / .woff2,
    "Minecraft" by Pwnage_Block (2011), made with FontStruct
    http://fontstruct.com/fontstructions/show/432966
    License: Creative Commons Attribution Share Alike 3.0
